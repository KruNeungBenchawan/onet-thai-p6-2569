🔤 คำควบกล้ำแท้ vs คำควบกล้ำไม่แท้

  • ควบกล้ำแท้ (ควบ ร, ล, ว ออกเสียงคู่กัน) : กราบ, พระ, กลม, เพลง, กวาด, ขวาน, ตรากตรำ, กวัดแกว่ง, ปลอดโปร่ง
  • ควบไม่แท้ กลุ่มที่ 1 (จร, ซร, ศร, สร ➔ ไม่ออกเสียง ร) :
    จริง (จิง), ไซร้ (ไซ้), เศร้าโศก (เส้า-โสก), ศรัทธา (สัด-ทา), ศรี (สี), สร้าง (ส้าง), เสร็จ (เส็ด), สระน้ำ (สะ-น้ำ), สร้อย (ส้อย), สร่างไข้ (*ยกเว้น: สระผม อ่านว่า สะ-หระ-ผม)
  • ควบไม่แท้ กลุ่มที่ 2 (ทร ➔ ออกเสียงเป็น ซ) :
    ทรง, ทราบ, ทราม, ทราย, แทรก, ทรุดโทรม, มัทรี, อินทรี, นนทรี, พุทรา, ทรัพย์สิน, ทรวงอก, ฉะเชิงเทรา (*ระวัง! นิทรา, จันทรา เป็นควบแท้)

🎵 คำที่มีอักษรนำ & คำที่มีตัวการันต์ (์)

  • อักษรนำ 1 พยางค์ : ห นำ (หนาว, ใหญ่, แหวน, เหงื่อ) และ อ นำ ย มี 4 คำ คือ อย่า, อยู่, อย่าง, อยาก
  • อักษรนำ 2 พยางค์ (อักษรสูง/กลาง นำอักษรต่ำเดี่ยว ง ญ ณ น ม ย ร ล ว) : พยางค์หน้าออกเสียง อะ ครึ่งเสียง พยางค์หลังผันวรรณยุกต์ตามตัวหน้า เช่น ขยี้, ฉลาด, ถนน, ผลิต, ฝรั่ง, สงบ, สว่าง, ตลาด, จมูก, ตลก, อร่อย, องุ่น, ดำริ, ตำหนิ
  • ตัวการันต์ 2 ตัว/กลางคำที่ออกบ่อย : ดวงจันทร์, พระอินทร์, วิทยาศาสตร์, ภาพลักษณ์, สัญลักษณ์, บริสุทธิ์, พันธุ์ไม้, กษัตริย์ (กะ-สัด), พราหมณ์ (พราม), ชอล์ก, กอล์ฟ

🔖 เครื่องหมายวรรคตอนและอักษรย่อที่ออกสอบบ่อย

  • ฯ (ไปยาลน้อย) : ย่อคำยาวให้สั้นลง เวลาอ่านต้องอ่านเต็ม เช่น กรุงเทพฯ (กรุงเทพมหานคร)
  • ฯลฯ (ไปยาลใหญ่) : ละข้อความท้าย เวลาอ่านต้องอ่านว่า "ละ" หรือ "และอื่นๆ"
  • ๆ (ไม้ยมก) : อ่านซ้ำคำหน้า (❌ ห้ามเขียน "นาๆ ชาติ" ต้องเขียน "นานาชาติ")
  • ร.ร. = โรงเรียน  |  รร. = โรงแรม (ระวังจุด!)
  • รพ. = โรงพยาบาล  |  ปณ. = ไปรษณีย์
  • ตร. = ตำรวจ  |  ศธ. = กระทรวงศึกษาธิการ
  • พ.ศ. = พุทธศักราช  |  ครม. = คณะรัฐมนตรี
๖ ฯ ๘ (ค่ำ) ๑๒

🌙 แผนภาพช่วยจำ : การอ่านวัน เดือน ปี แบบไทย (จันทรคติ)

🔴 เลขหน้า ฯ (วันทั้ง 7) : ๑=อาทิตย์, ๒=จันทร์, ๓=อังคาร, ๔=พุธ, ๕=พฤหัสบดี, ๖=ศุกร์, ๗=เสาร์

🔵 เลขบน ฯ = ข้างขึ้น (ขึ้น ๑ ค่ำ – ๑๕ ค่ำ)  |  🟢 เลขล่าง ฯ = ข้างแรม (แรม ๑ ค่ำ – ๑๔/๑๕ ค่ำ)

🟣 เลขหลัง ฯ (เดือนไทย 12 เดือน) : เดือน ๑ = เดือนอ้าย, เดือน ๒ = เดือนยี่, เดือน ๓ = เดือนสาม ... เดือน ๑๒ = เดือนสิบสอง

✅ ตัวอย่างในกรอบอ่านว่า : "วันศุกร์ ขึ้นแปดค่ำ เดือนสิบสอง"

📌 1.2 คลังคำที่มีความหมายโดยตรง vs ความหมายโดยนัย (ท 1.1 ป.6/2)

คำศัพท์ ความหมายโดยตรง (ตามพจนานุกรม) ความหมายโดยนัย (เปรียบเทียบ/แฝงความหมาย)
มือสะอาด / มือขวา มือที่ล้างสะอาดแล้ว / มือข้างขวา มือสะอาด = ซื่อสัตย์สุจริต ไม่โกง | มือขวา = คนสนิทที่ไว้ใจช่วยงานสำคัญ
มืออ่อน / มือเติบ / มือเย็น มือที่นิ่มอ่อนแรง / - / มือที่เย็น มืออ่อน = นอบน้อมไหว้สวย | มือเติบ = ใช้เงินฟุ่มเฟือย | มือเย็น = ปลูกต้นไม้งาม
ดาว / เพชร ดวงดาวบนท้องฟ้า / อัญมณีเพชร ดาว = บุคคลที่โดดเด่นในวงการ | เพชร = คนดีมีคุณค่าและความสามารถสูง
เก้าอี้ ที่นั่งมีขาสำหรับนั่งพัก ตำแหน่งหน้าที่การงานหรืออำนาจ ("เขากำลังรักษาเก้าอี้ผู้จัดการ")
หิน / กล้วย / หมู ก้อนหิน / ผลกล้วย / เนื้อหมู หิน = ยากมาก ("ข้อสอบปีนี้หินสุดๆ") | กล้วย, หมู = เรื่องง่ายมาก
แกะดำ / แพะรับบาป แกะขนสีดำ / สัตว์แพะในพิธี แกะดำ = คนที่ทำตัวต่างจากกลุ่มในทางไม่ดี | แพะรับบาป = คนที่รับผิดแทนคนอื่น
หัวหมุน / หน้ามืด / ตีนแมว อาการเวียนหัว / จะเป็นลม / เท้าแมว หัวหมุน = ยุ่งวุ่นวายมาก | หน้ามืด = ขาดสติเพราะความโลภ/โกรธ | ตีนแมว = ขโมยย่องเบา

🎨 โวหารการเขียนและโวหารภาพพจน์ 6 ชนิด

  • 1. อุปมาโวหาร (เปรียบว่าเหมือน) : มีคำเชื่อม เหมือน, เสมือน, ดุจ, ดัง, ดั่ง, เพียง, ประหนึ่ง, เฉก, เช่น, ปาน, ราวกับ
  • 2. อุปลักษณ์ (เปรียบว่าเป็น) : ใช้คำว่า เป็น, คือ ("ครูคือเรือจ้าง")
  • 3. บรรยายโวหาร : เล่าเหตุการณ์/ขั้นตอนตรงไปตรงมาตามลำดับ
  • 4. พรรณนาโวหาร : ใช้คำไพเราะละเอียดลึกซึ้งให้เห็นภาพและเกิดอารมณ์
  • 5. เทศนาโวหาร : สั่งสอน แนะนำ ชี้แนะแนวทางความดีงาม
  • 6. สาธกโวหาร : ยกตัวอย่างเรื่องราวหรือนิทานสั้นๆ มาประกอบ

✅ ข้อเท็จจริง vs 💭 ข้อคิดเห็น & ใจความสำคัญ

  • ข้อเท็จจริง (Fact) : พิสูจน์ได้ มีหลักฐาน สถิติ กฎธรรมชาติ
  • ข้อคิดเห็น (Opinion) : ความรู้สึก ความเชื่อ การคาดคะเน ข้อเสนอแนะ
    🔑 คีย์เวิร์ดข้อคิดเห็น : ควร, น่าจะ, คงจะ, อาจ, อาจจะ, เหมือน, คิดว่า, เชื่อว่า, ที่สุด
  • ตำแหน่งประโยคใจความสำคัญ 4 แบบ : (1) อยู่ต้นย่อหน้า (พบบ่อยสุด)  (2) อยู่ท้ายย่อหน้า (หลังคำว่า ดังนั้น, จึง)  (3) อยู่ทั้งต้นและท้าย  (4) สรุปรวมเองจากทุกประโยค

💡 4.6 คลังสำนวนไทย สุภาษิต และคำพังเพยยอดฮิต (ท 4.1 ป.6/6)

  • ขี่ช้างจับตั๊กแตน : ลงทุนลงแรงมากแต่ได้ผลตอบแทนน้อยไม่คุ้มค่า
  • ตำน้ำพริกละลายแม่น้ำ : เสียทรัพย์สินไปโดยไม่ได้ประโยชน์อะไรกลับมา
  • วัวหายล้อมคอก : เกิดความเสียหายขึ้นแล้วจึงค่อยคิดหาทางป้องกัน
  • ชิงสุกก่อนห่าม : ทำสิ่งที่ไม่สมควรแก่วัยหรือทำก่อนถึงเวลาอันควร
  • เห็นช้างขี้ ขี้ตามช้าง : เลียนแบบคนรวยทั้งที่ตนเองไม่มีกำลังทรัพย์พอ
  • ตักน้ำรดหัวตอ / สีซอให้ควายฟัง : สั่งสอนอย่างไรก็ไม่รับฟัง ไม่เกิดผล
  • ใกล้เกลือกินด่าง : อยู่ใกล้สิ่งดีมีค่าแต่กลับมองข้ามไปคว้าสิ่งด้อยค่า
  • คางคกขึ้นวอ / กิ้งก่าได้ทอง : คนฐานะต่ำต้อยพอได้ดีก็ลืมตัวเย่อหยิ่ง
  • น้ำขุ่นไว้ใน น้ำใสไว้นอก : เก็บความโกรธไว้ในใจแล้วแสดงสีหน้ายิ้มแย้ม
  • มือไม่พายเอาเท้าราน้ำ : ไม่ช่วยทำงานแล้วยังคอยขัดขวางคนอื่น

🌸 ด่านที่ 5 : อุทยานวรรณคดีและวรรณกรรม (มาตรฐาน ท 5.1)

3 ตัวชี้วัด • ปรนัย 3 ข้อ = 12 คะแนน
วรรณคดี / บทอาขยานสำคัญ วรรคทองที่ต้องจำ คุณค่าและข้อคิดในการนำไปใช้จริง
1. โคลงโลกนิติ "ปลาร้าพันห่อด้วย ใบคา... คือคนหมู่ไปหา คบเพื่อน พาลนา" / "ห้ามเพลิงไว้อย่าให้ มีควัน... ห้ามดั่งนี้ไว้ได้ จึ่งห้ามนินทา" • เลือกคบคนดีเป็นมิตร หลีกเลี่ยงคนพาล
• เข้าใจสัจธรรมว่าไม่มีใครหนีคำนินทาพ้น ให้ตั้งใจทำความดีต่อไป
2. ตนเป็นที่พึ่งแห่งตน & ผู้รู้ดีเป็นผู้เจริญ "เราเกิดมาทั้งทีชีวิตหนึ่ง อย่าหมายพึ่งผู้ใดให้เขาหยัน" / "มวลมนุษย์ผู้เปรื่องปรีชาชาญ เพราะศึกษาเชี่ยวชาญจึงปราดเปรื่อง" • มีความเพียรพยายาม พึ่งพาตนเอง และหมั่นศึกษาหาความรู้พัฒนาตนเองเสมอ
3. สุภาษิตสอนหญิง (สุนทรภู่) "อันอ้อยตาลหวานลิ้นแล้วสิ้นซาก แต่ลมปากหวานหูไม่รู้หาย ถึงเจ็บอื่นหมื่นแสนจะแคลนคลาย เจ็บจนตายนั้นเพราะเหน็บให้เจ็บใจ" • ระมัดระวังคำพูด เลือกใช้ถ้อยคำที่ไพเราะอ่อนหวานและไม่พูดจาเหน็บแนมทำร้ายจิตใจผู้อื่น
4. นิทานพื้นบ้าน (เช่น มัดตะเกียบ) ตะเกียบแยกเดี่ยวหักง่าย แต่เมื่อมัดรวมกันแน่นไม่มีใครหักได้ • ความสามัคคีปรองดองกันในหมู่คณะก่อให้เกิดพลังที่เข้มแข็ง
